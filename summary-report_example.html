安全漏洞审查

2 严重2 高危3 中危
▼
严重SSRF 服务端请求伪造server/app/controller/TutorialController.php:fetchUrl()
控制器直接使用用户输入的URL发起服务端请求，未做任何域名白名单校验，攻击者可访问内网资源
⚠️ 漏洞代码
$url = $this->request->param('url');
$content = file_get_contents($url);
return json(['code' => 200, 'data' => $content]);
✅ 修复代码
$url = $this->request->param('url');
$allowed = ['jsonplaceholder.typicode.com'];
$host = parse_url($url, PHP_URL_HOST);
if (!in_array($host, $allowed)) {
    return json(['code'=>403,'msg'=>'域名不在白名单']);
}
$content = file_get_contents($url);
严重任意文件上传漏洞server/app/controller/CoupleController.php:uploadPhoto()
照片上传接口未校验文件类型和大小，攻击者可上传PHP WebShell获取服务器控制权
⚠️ 漏洞代码
$file = $this->request->file('file');
$saveName = Filesystem::disk('public')
    ->putFile('couple', $file);
return json(['code'=>200,'data'=>$saveName]);
✅ 修复代码
$file = $this->request->file('file');
$ext = strtolower($file->getOriginalExtension());
$allowed = ['jpg','jpeg','png','gif','webp'];
if (!in_array($ext, $allowed)) {
    return json(['code'=>400,'msg'=>'仅允许图片文件']);
}
if ($file->getSize() > 5*1024*1024) {
    return json(['code'=>400,'msg'=>'文件不能超过5MB']);
}
$saveName = Filesystem::disk('public')
    ->putFile('couple', $file);
高危硬编码用户认证server/app/middleware/Auth.php
Auth中间件硬编码 userId=1，所有请求均以同一用户身份执行，无真实认证机制
⚠️ 漏洞代码
$request->userId = 1;
return $next($request);
✅ 修复代码
$token = $request->header('Authorization');
$payload = Jwt::verify($token);
if (!$payload) {
    return json(['code'=>401,'msg'=>'未登录']);
}
$request->userId = $payload['uid'];
return $next($request);
高危SQL注入风险（Db::raw拼接）server/app/controller/TodoController.php:index()
排序字段使用 Db::raw() 直接拼接用户输入，存在SQL注入风险
⚠️ 漏洞代码
$sort = $this->request->param('sort', 'id');
$order = $this->request->param('order', 'desc');
->order(Db::raw($sort . ' ' . $order))
✅ 修复代码
$allowedSort = ['id','title','priority','created_at','due_date'];
$allowedOrder = ['asc','desc'];
$sort = in_array($sort, $allowedSort) ? $sort : 'id';
$order = in_array($order, $allowedOrder) ? $order : 'desc';
->order($sort, $order)
中危CORS配置过于宽松server/app/middleware/Cors.php
允许所有来源（Access-Control-Allow-Origin: *），生产环境应限制为前端域名
⚠️ 漏洞代码
header('Access-Control-Allow-Origin: *');
✅ 修复代码
$origin = $request->header('origin');
$allowed = ['http://localhost:3210']
    . config('app.allowed_origins', []);
if (in_array($origin, $allowed)) {
    header('Access-Control-Allow-Origin: ' . $origin);
}
中危缺少输入验证和XSS防护所有控制器
所有控制器直接使用 param() 获取参数后写入数据库，未做验证和转义，存在存储型XSS风险
⚠️ 漏洞代码
$data = $this->request->param();
Db::name('flower_todos')->insert($data);
✅ 修复代码
$data = $this->request->only([
    'title','description','priority','due_date'
]);
try {
    validate(TodoValidate::class)
        ->check($data);
} catch (ValidateException $e) {
    return json(['code'=>400,'msg'=>$e->getError()]);
}
Db::name('flower_todos')->insert($data);
中危敏感信息泄露server/.env
数据库密码等敏感信息存储在 .env 文件中，但未加入 .gitignore，可能被提交到版本库
建议：确保 .env 已加入 .gitignore，生产环境使用环境变量注入而非文件
